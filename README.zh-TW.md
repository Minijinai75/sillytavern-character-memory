# CharMemory — SillyTavern 擴充套件

CharMemory 自動從您的聊天中提取結構化記憶，並將它們儲存在角色的資料庫中。SillyTavern 內建的向量儲存功能會在生成時檢索最相關的記憶——您的角色會記得發生過的事情。

>**從 1.x 版升級？**
此版本包含大量底層程式碼變更，修改了提取提示和提取記憶的結構。如果您使用過舊版本，應在更新前備份當前檔案，並且您會想要比較您編輯過的提示與新版本的差異。

## 這適合您嗎？

**CharMemory 是為角色卡定義角色身份，而資料庫角色記憶捕捉隨時間發生的事情的設定而建立的。**

適合您，如果：
- 您使用**角色卡**並希望角色能記住跨會話的事情
- 您進行 **1對1 或群組聊天**
- 您希望記憶儲存為**純文字、可編輯的檔案**——而不是鎖定在資料庫中

可能不適合您，如果：
- 您的記憶工作流程基於知識書（世界資訊觸發條目）
- 您的角色卡包含多個角色
- 您不使用角色卡

CharMemory 和基於知識書的記憶擴充套件可以共存——它們使用不同的儲存機制。

CharMemory 不會觸碰您的知識書，因此如果知識書包含關於角色世界的資訊，它們可以補充資料庫記憶。CharMemory 確實為新的資料庫檔案使用自己的結構化 markdown 格式。它可以選擇性地將您現有的檔案處理成相同的格式。

## 運作原理

CharMemory 為您的角色提供跨聊天的持久記憶。以下是簡短版本：

1. **您正常聊天。** 每 20 則訊息（可配置），CharMemory 會將最近的對話發送到 LLM，並要求它挑選出重要的內容——關係、事件、事實、情感時刻。

2. **記憶被儲存為純文字檔案**，附加到角色（在 SillyTavern 的「資料庫」中）。您可以隨時閱讀和編輯此檔案——它只是 markdown 格式的項目符號。

3. **當角色說話時，相關記憶會自動檢索。** SillyTavern 的向量儲存就像記憶檔案的搜尋引擎。它會找到與當前對話最相關的記憶，並悄悄地將它們包含在 LLM 看到的提示中。角色不「知道」它正在閱讀記憶——它只是有相關的上下文可用，就像人們如何回憶與正在討論的事情相關的細節。

**關鍵好處：與同一角色開始新聊天，他們可以引用之前發生的事情。** 這不是完美的照相記憶——它更接近人們實際記憶的方式，即相關細節會根據正在談論的內容浮現。

> **什麼是向量儲存？** 它是 SillyTavern 的內建功能（不是 CharMemory 的一部分），就像文字檔案的搜尋引擎。它將文字轉換為數值表示（「嵌入」），這樣它就可以找到在*語義上相似*於當前對話的段落，即使它們不共享確切的詞彙。沒有它，記憶會被儲存但永遠不會被檢索——角色不會回憶起任何東西。請參閱[入門指南 → 確保向量儲存已啟用](docs/getting-started.md#make-sure-vector-storage-is-enabled)以了解設定步驟。

## 功能亮點

- **自動提取** — 自動從您當前的聊天中提取記憶。設定後無需手動步驟。
- **群組聊天支援** — 每個群組成員都有自己的記憶檔案，在單次通過中提取。從一個地方查看和編輯所有成員的記憶，包括每個角色的完整資料庫瀏覽器。
- **注入檢視器** — 即時側邊欄顯示任何訊息注入了哪些記憶，包括知識書條目、擴充提示和每個來源的權杖估計。
- **提示明細** — 準確查看您的上下文視窗使用情況。注入檢視器顯示每個類別的權杖明細（系統、角色卡、知識書、資料庫、範例、聊天歷史），帶有堆疊條和減少使用的可操作提示。
- **向量儲存健康檢查** — 交通燈指示器標記錯誤配置的設定並告訴您如何修復，這樣您就不用猜測為什麼記憶沒有顯示。
- **完整記憶控制** — 使用統一的區塊編輯器（內聯編輯、撤銷、尋找/替換）瀏覽、編輯或刪除個別記憶。使用預覽和撤銷功能整合重複項。一次從所有聊天中批次提取。
- **靈活的 LLM 連接** — 使用專用 API 提供商、重用現有的 SillyTavern 連接配置文件、通過 WebLLM 執行本地模型，或搭載您的主聊天 LLM。
- **高度可配置的提取提示** — 為 1對1 和群組聊天以及記憶檔案整合和轉換提供單獨的提示。
- **引導式設定** — 設定精靈測試您的 LLM 連接，檢查向量儲存，並處理現有記憶檔案轉換，大約 2 分鐘。
- **平板和手機支援** — 在觸控裝置上，儀表板會作為浮動面板開啟，帶有觸控友好的控制項。手機佈局會為小螢幕加寬抽屜。如果自動偵測與您的裝置不匹配，請在設定 > 進階 > 顯示模式中覆蓋它。請在 GitHub 上[回報問題](https://github.com/bal-spec/sillytavern-character-memory/issues)，說明它在您的裝置上的行為。
- **純檔案** — 記憶以可讀、可編輯的 markdown 格式儲存在角色的資料庫中。沒有資料庫，沒有鎖定。

## 您需要什麼

- 可運作的 **SillyTavern** 安裝
- **LLM API 金鑰**（OpenRouter、Groq、DeepSeek、NanoGPT 等）——或使用 **Pollinations**（免費，無需金鑰）或**本地伺服器**（Ollama、LM Studio 等）
- **向量儲存** — 隨 SillyTavern 一起提供，只需啟用

## 安裝

**1.** 點擊 SillyTavern 頂部欄中的**擴充套件**圖示（拼圖圖示）

**2.** 點擊**安裝擴充套件** → 貼上此 URL → **僅為我安裝**：
```
https://github.com/bal-spec/sillytavern-character-memory
```

**3.** 開啟聊天並在擴充套件中向下捲動 — **CharMemory** 出現在底部。設定精靈應在首次執行時自動開啟。如果沒有，請點擊面板標題中的**魔杖圖示**以開啟設定精靈。

**4.** 精靈會引導您連接 LLM 和檢查向量儲存。大約需要 2 分鐘。

→ **[入門指南](docs/getting-started.md)** 有精靈的逐步演練和您的第一次提取。

## 開始之前

CharMemory 將記憶儲存為角色資料庫中的純檔案。像**整合**、**全部替換**和**清除所有記憶**這樣的工具會修改或刪除這些檔案，並且不能總是撤銷。**在進行大量變更之前備份您的資料庫檔案** — 使用 SillyTavern 的內建[備份工具](https://docs.sillytavern.app/usage/user-settings/)或從資料庫下載個別檔案。
